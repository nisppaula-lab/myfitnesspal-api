# MyFitnessPal API for Muse

Private REST bridge for Nicolle's MyFitnessPal account. It adapts the
MIT-licensed open-source MyFitnessPal MCP server into a small REST surface
that Muse can reach through a custom connector.

Capabilities:

- read a day's food diary
- search MyFitnessPal foods and read food details
- add a food to Breakfast, Lunch, Dinner, or Snacks
- remove a diary entry when an exact entry is identified
- read/write water, goals, and body measurements

See `API.md` and `DEPLOY.md`.
